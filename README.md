## How this is organized

Each class gets its own folder with a consistent structure:

```
IST-XXXX-course-name/
├── README.md          # What the class covered and what I got out of it
├── labs/              # Hands-on lab work and writeups
├── projects/          # Larger assignments and final projects
└── notes/             # Key concepts worth keeping (not everything)
```

## Note about Raccoon Recon

My biggest project from IST 4620 outgrew this repo and lives in its own repository: [raccoon-recon](https://github.com/jruggles656/raccoon-recon). It's a web-based penetration testing reconnaissance toolkit built in Go with real-time WebSocket output, a REST API, and PDF report generation.
