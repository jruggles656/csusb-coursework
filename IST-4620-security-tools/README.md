# IST 4620 — Penetration Testing & Ethical Hacking

Spring 2026 | CSUSB

## What this class covers

Hands-on penetration testing methodology: reconnaissance, scanning, exploitation, and reporting. Heavy emphasis on building tools and understanding what's happening under the hood.

## Key projects

- **[Raccoon Recon](https://github.com/jruggles656/raccoon-recon)** — A web-based reconnaissance toolkit built in Go. This project started as a class assignment and grew into a full application with a REST API, WebSocket streaming, SQLite persistence, and PDF report generation. Lives in its own repo.
